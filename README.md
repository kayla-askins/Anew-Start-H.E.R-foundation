# Anew Start H.E.R. Foundation — Website Prototype

A React-based website prototype designed for **Anew Start H.E.R. Foundation**, a nonprofit founded by Roneshiea Walker that supports women and youth working toward a fresh start.

🌐 **Live Preview:** [View the prototype](https://app.landingsite.ai/website-preview?id=9f477ea9-3c87-46b2-9393-e054ba4400b7)

## About the Project

I designed and prototyped this 4-page website in one week to give the foundation a clear, mission-aligned digital presence. The site introduces visitors to the foundation's purpose, the founder's story, and how to get involved.

## Design Direction

The visual identity is built around the theme **"light from shadows"** — reflecting the foundation's mission of helping people rebuild after hardship.

- **Color palette:** Plum-to-gold gradient, signaling transformation
- **Tone:** Warm, hopeful, professional
- **Structure:** 4 pages covering mission, programs, founder story, and contact

## How It Was Built

- Designed React component structure and page flow from scratch
- Authored a detailed master prompt translating the design system into AI-executable build instructions for Landingsite's no-code AI builder
- Iterated on layout, copy, and visual hierarchy based on founder feedback
